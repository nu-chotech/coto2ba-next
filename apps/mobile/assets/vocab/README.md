# assets/vocab

`input.txt` は **入力語彙**（SPEC §4.2 / §8.7）。1 行 1 語、UTF-8、**ソート済み**、約 1.5MB。
`tools/pipeline` の `02_prune.py` が生成する。

いまリポジトリに入っているのは **空のプレースホルダ**。
Metro は `require()` を静的に解決するのでファイル自体が存在しないとバンドルが通らない。
中身が空のあいだ `src/lib/vocab.ts` は判定をスキップし、`isKnownWord()` は常に `true` を返す
（OOV の最終判定はサーバー）。

パイプラインが生成したら、このファイルをそのまま上書きすること。
