# 実機確認チェックリスト

> 2026-09-18 の改修後、**Expo Go の実機でしか確認できないこと**をまとめた。
> Web では `SkiaGate` のフォールバック・ハプティクスの不在・タッチの扱いの違いがあり、
> 以下は実機でしか判断できない。

**所要およそ 15 分。** 上から順にやれば一通り触れる。

---

## 0. 準備

```bash
cd apps/mobile && pnpm start
```
出た QR を iPhone の Expo Go で読む（API は本番を向く）。

**確認**: スプラッシュに**ロゴのマーク**（鍋＋キラキラ）が出るか。
以前は 228×213 のほぼ空白だった。ライト/ダークで地の色が切り替わるか。

---

## 1. ライト/ダーク（全画面）

端末の外観設定を切り替えて、ロビー → ゲーム → 結果 → 図鑑 → ランキング → 設定 を見る。

- [ ] **文字が読めるか**（特に**タブバーの選択中のラベル**。ここは実測でライト 1.18:1 まで落ちていた）
- [ ] ロゴがライトで黒、ダークで白に切り替わるか
- [ ] **図鑑だけはライトでも暗いまま**か（意図的な例外）
- [ ] ガラスが破綻していないか

---

## 2. 比率のホイール（いちばん触る場所）

ゲーム画面で回す。

- [ ] **クルクル回る感じがするか**（オリジナルのこだわりを戻したもの）
- [ ] 段が変わる瞬間に**ハプティクスが来るか**。連打しても不快でないか
- [ ] **ホイールの中心を指で押さえて微妙に動かしても比率が飛ばないか**
      （修正前は 4px のブレで 2 段飛んだ）
- [ ] **ホイールの上で縦にスワイプしたとき、画面がスクロールするか**（比率が変わらないこと）
- [ ] 慣性が自然か。行き過ぎて戻るか
- [ ] **回転中に 2 本目の指が触れたときの挙動**（Web では検証できなかった箇所）

---

## 3. 効果音（音量を上げて）

- [ ] ホイールの段が変わる音が**うるさくないか**（ほぼ気配のレベルのはず）
- [ ] 混ぜたときの音に手応えがあるか
- [ ] **クリアの音だけ厚いか**（「静かな土台＋演出で爆発」の設計）
- [ ] 遠ざかったとき・弾かれたときの音が**責める感じでないか**

数値上はクリックノイズ・耳障りな帯域・クリッピングすべてゼロだが、
**「聴いて良いと感じるか」は数値では代替できない**。気に入らなければ
`tools/pipeline/scripts/sounds_lib.py` の `SOUND_DESIGN` を変えて `pnpm pipeline:sounds` で作り直せる。

---

## 4. 図鑑（展示の山場）

結果画面の「この軌跡を見る」から入る。

- [ ] **開いた瞬間に自分の軌跡が主役に見えるか**（点群が主役に見えたら失敗）
- [ ] **経路を切り替えたとき、ラベルが節に付いてくるか**
      （修正前は前のカメラ位置に取り残された。**実機でも壊れていたはずの欠陥**）
- [ ] 回している最中と、**指を止めた直後**にラベルがずれないか
- [ ] 発光（`BlurMask`）が綺麗に出るか。**Web では一度も見られなかった箇所**
- [ ] **二本指タップ**がピンチと誤爆しないか
- [ ] カクつかないか（Web では 60fps を維持していた）

---

## 5. 画面の動線

- [ ] **ギブアップが見つけやすい場所にあるか**（旧実装は Alert の 2 段重ね）
- [ ] フリーモードを途中でやめてロビーに戻り、**「つづきから」で戻れるか**
- [ ] 戻る操作が期待どおりの場所に戻るか

---

## 6. 設定画面（以前エラーが出た場所）

- [ ] **表示名を変える**。エラーが出ないか（`サーバーの応答を解釈できません` が出ないこと）
- [ ] **ブースモードを ON にする**。同上
- [ ] ブースモードで「次の人へ」が効くか

---

## 7. 対戦（2 台あれば）

- [ ] 部屋を作り、**もう 1 台で QR を読んで参加できるか**（ブースの主動線）
- [ ] 開始 → 両方で数手 → 片方がクリア → 両方が結果画面
- [ ] **「もう一度」で両方が次の部屋に移るか**
- [ ] 順位バーに**他人の打った語が出ていないか**（出ていたら競技として破綻）

---

## 8. 最後に

- [ ] **一度もクラッシュしなかったか**
- [ ] 気持ち悪かったところを**雑でよいので箇条書き**にする

数値で確認済みのことは再確認しなくてよい（テスト 392 件、CI 6 ステップ、
Web での通しプレイ、レビュー 8 本すべて）。**実機でしか分からないことだけ**を見てほしい。
