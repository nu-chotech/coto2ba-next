# ゴール語の種リスト（手で選んだ「絵になる語」）
#
# 品詞だけでは「政令」と「望遠鏡」を区別できない。Wikipedia の頻度上位は行政・法律・
# 報道の語彙が厚く、機械的に選ぶとゴールが「政令 / 官能 / 工法 / 目処」になってしまう。
# ここに人が選んだ語を置き、04_goal_pool.py が **これを優先して**ボット検証する。
#
# 条件: 出力語彙に存在すること / 2 文字以上 / 目的地として一目で絵が浮かぶこと。
# ここに無い語も算法的な候補として拾われるので、埋まらなくても問題ない。
# 追加したら `pnpm pipeline:goal-pool` を流し直すこと。
